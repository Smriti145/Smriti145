### 🔗 [TraceChain](https://github.com/Smriti145/TraceChain)
A product provenance system with a manufacturer web portal, an Express/Prisma API, and a React Native app.

Manufacturers generate unique QR codes for products; scanning a code verifies authenticity and shows the full supply-chain journey.

**Highlights**
- Role-based API access with JWT auth
- PostgreSQL + Prisma data layer
- Public HTML provenance report per QR
- Demo data across food, pharma, textiles, electronics

`Node.js` `Express` `Prisma` `PostgreSQL` `React Native` `TypeScript`
